Hospitality Analytics Dashboard
This project was completed during my 3-month Data Analyst Internship at ExcelR.
The main objective of this project was to analyze hospitality booking data and create interactive dashboards to understand hotel performance. I worked on data cleaning, writing SQL queries, calculating KPIs, and building dashboards using different tools.

Tools Used
- Microsoft Excel
- MySQL
- Power BI
- Tableau

Key KPIs
- Total Revenue
- Occupancy %
- ADR
- RevPAR
- Total Bookings
- Cancellation %
- No Show %
- Checked Out %
- Total Capacity

Dashboard Features
- Revenue Analysis
- Occupancy Analysis
- Booking Status Analysis
- Revenue by City
- Revenue by Room Category
- Revenue Trend
- Booking Platform Analysis
- Interactive Filters

What I Learned
- Data Cleaning
- SQL Queries
- Data Modeling
- Dashboard Design
- KPI Creation
- Data Visualization
- Business Analysis
This project helped me understand how raw data can be converted into meaningful business insights using different analytics tools.
